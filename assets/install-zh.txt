AI 用量监控 v2.1

新增托盘与贴边悬浮窗。最小化或关闭窗口默认收进托盘；右键托盘选择“退出程序”可完全退出。悬浮窗可拖动，贴左右边缘后自动收起，鼠标移入展开。登录状态自动恢复，无需每次打开都重新登录；授权失效或主动退出账号后除外。

本安装包包含程序及 Python / Qt 运行环境，无需另行安装 Python。

Codex：请先安装官方 Codex CLI 或桌面应用。监控程序会自动查找 codex.exe，也支持手动选择。登录在官方浏览器页面完成，本程序使用独立的 Codex 登录状态。

Claude Code：请安装并登录最新版官方 Claude Code。在监控程序中启用用量接入，然后重启 Claude Code 并正常使用。用量来自活动时更新的状态栏，并非后台轮询 Claude 账号。Pro / Max 额度仅在 Claude Code 提供时显示。如已有状态栏，程序会先询问是否替换并保存原设置备份。

语言：安装时选择的语言将用于程序界面。安装后可切换简体中文与 English，重新打开程序后生效。

可通过 Windows“已安装的应用”卸载。本地历史和独立 Codex 登录状态会保留；如需清除登录，请先在程序内退出 Codex 登录。
